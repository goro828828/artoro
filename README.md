# ARTORO（アートロ）

すれ違いで作品を交換するアプリ「ARTORO」のWeb版プロトタイプです。

SNSはアルゴリズムで表示が決まるため、作品が多くの人に届きにくいことがあります。ARTOROは、アルゴリズムにたよらず、すれ違った人どうしで作品を送り、受け取れる仕組みを目指しています。

## 公開ページ

GitHub Pages で公開しています： https://goro828828.github.io/artoro/

## 主な機能

- **ホーム**：すれ違った人がサムネに設定している作品を、額縁に入れて横スライドで表示。右上のスイッチで、出会った場所の地図表示に切り替え（クリーム色のホワイトアウト）。
- **相手の美術館**：作品をタップすると、その人の作品が壁に並んだ美術館へ。詳細ではすれ違った場所と日時を表示。
- **ガチャ**：作品コイン（毎日5枚）で1日5回。ランダム／水彩画／油彩画などジャンルを選べる。地球儀と画材が回るアニメーション、封筒から作品が届く演出つき。
- **マイページ**：マイ美術館（自分の作品）と他人の作品（コレクション）。作品の追加・編集、すれ違い通信のサムネ設定。
- **設定**：Instagramの構成を参考にした設定画面（すれ違い通信、位置情報の記録、お知らせ、プライバシー、ブロックなど）。

## このデモの制限

- ブラウザではBluetoothによるすれ違い通信ができないため、ホームの「すれ違いを試す（デモ）」で再現しています。
- 作品・作者・場所はサンプルで、作品画像はプログラムで生成しています。
- データは見ている人のブラウザ（localStorage）の中だけに保存され、ほかの人とは共有されません。

## 構成

ビルド不要の静的サイトです。`index.html` 1枚にHTML・CSS・JavaScriptがまとまっています。ローカルではファイルをブラウザで開くだけで動きます。
